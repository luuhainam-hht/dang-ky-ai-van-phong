# Đăng ký khóa học AI Ứng Dụng Cho Khối Văn Phòng

Trang đăng ký học viên (GitHub Pages). Dữ liệu gửi về Google Sheet qua Google Apps Script.

- `index.html` – trang đăng ký
- `config.js` – địa chỉ Web App của Apps Script (`SCRIPT_URL`)
- `apps-script.gs` – code dán vào Apps Script của Google Sheet
